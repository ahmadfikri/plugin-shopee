📦 Data Training (Collective Intelligence)

Tiap klik 💾 Simpan Data Training di panel produk menyimpan fitur produk ke penyimpanan lokal. Sekali seminggu, export dan kirim ke koordinator untuk digabung jadi dataset kolektif — nanti dipakai melatih model prediksi bersama. (Cloud service menyusul; sekarang manual export.)

Halaman detail produk memberi data terkaya (rating, review, bintang, terjual, video). Halaman listing / bulk scan memberi data lebih tipis tapi jumlahnya banyak. Data tipis TIDAK akan menimpa data kaya untuk produk yang sama.
