## v0.9.33 — Caption engagement tanpa engagement bait
Permintaan Fikri: caption harus mendorong orang like dan share, tetap SEO friendly.

- `DEFAULT_CAPTION_PROMPT` (src/ai.js): aturan SEO tetap nomor satu (kata kunci
  utama di 3–6 kata pertama). Ditambah struktur engagement: satu momen relatable
  yang spesifik, satu hal berguna/penasaran, satu pertanyaan terbuka penutup, lalu
  ajakan cek link. Panjang 4–6 baris.
- **Tidak** meminta like/share/tag/komen kata tertentu/voting. FB/IG menurunkan
  jangkauan untuk engagement bait, yang ujungnya menaikkan CPC.
- Guard output `stripEngagementBait()` + `BAIT_PATTERNS`: membuang hanya
  KALIMAT bait, baris hashtag dan link tidak disentuh. Dipanggil di `ensureHashtags()`
  bersama `stripPrice` / `stripRating`.
- Test: `test/e2e-caption-engage.js` (13 skenario: 7 bait dibuang, 5 kalimat wajar
  dibiarkan, baris hashtag utuh). Langkah 29b di `run-all.sh`.
- Catatan: prompt tersimpan di Admin Panel (Prompt Caption) menimpa template bawaan.
  Kosongkan field itu supaya struktur baru dipakai. Guard tetap jalan.

## v0.9.34 — Filter niche + 🧬 Analisa pola champion (Ad Library)
- `nicheOf(ad)` mengelompokkan iklan dari teks iklan: Casing HP, Rumah/Dapur,
  Gadget, Fashion, Kecantikan, Lainnya.
- Bar 🎬 syabab: dropdown filter niche (termasuk ⭐ Niche champion = HP + Rumah).
  Iklan di luar filter dipudarkan di halaman dan disembunyikan dari 🏆 Top iklan.
  Pilihan disimpan di `localStorage` (`rm_fb_niche_filter`).
- Tombol `🧬 Analisa pola · skor TIER` di tiap kartu (di samping ⬇ Download video HD)
  + kolom **Pola** di Top iklan. Klik = rincian skor + pola kompetitor niche itu.
- `polaScore(ad, competitorStats(list))`, 0–100:

  | Faktor | Poin |
  |---|---|
  | Lama tayang (penuh di 30 hari) | 35 |
  | Variasi (penuh di 5) | 15 |
  | Niche: HP/Rumah 25, Gadget 10, Lainnya 5, Fashion/Kecantikan 0 | 25 |
  | Ada link Shopee | 10 |
  | Link sama dipakai ≥ 2 pengiklan | 10 |
  | Niche itu punya ≥ 3 iklan TERBUKTI di halaman | 5 |

  ≥ 70 CHAMPION, 45–69 MIRIP, < 45 LEMAH.
- Baseline dari data Fikri sendiri (43 campaign spend ≥ Rp60rb): 8 dari 8 champion
  casing HP atau rumah/dapur; fashion/kecantikan gagal (komisi/order kecil).
  **Hook rate tidak dipakai**: korelasi rank dengan ROAS −0,12 (champion 31%,
  gagal 34%). CPR dan order per 100 klik membedakan paling kuat, tapi baru ada
  setelah iklan kita sendiri jalan, jadi tidak bisa dinilai dari Ad Library.
- Skor = penyaring awal, bukan ramalan. Vonis tetap tes 7 hari + tanggal kembar.
- Test: `test/e2e-pola-champion.js` (langkah 43b) + tambahan di
  `test/e2e-browser-fbadlib.js` (tombol, kolom Pola, filter pudar/reset).

## v0.9.35 — Checkbox + 🔬 Analisa dalam (DeepSeek)
- Checkbox **Pilih untuk 🔬 Analisa dalam** di tiap kartu, tombol
  **🔬 Analisa dalam (N)** di bar (abu-abu kalau 0).
- Alur: link Shopee iklan yang dicentang dibuka di tab latar satu per satu
  (pakai `fbadlib-analyze` yang sama dengan Analisa TERBUKTI, maks 12, tab
  menutup sendiri) → `pp-verdict` sekarang juga mengirim harga, review, favorit,
  stok, kategori, EPC, PRO → `deepPrompt()` menggabungkan sinyal kompetitor +
  data produk + vonis model kita + baseline champion → DeepSeek (temperature 0,3)
  → `parseDeep()` → tabel skor 0–100 + COBA / UJI KECIL / LEWATI, alasan, risiko,
  angle kreatif. Harga dibuang dari angle. Jawaban non-JSON ditampilkan apa adanya.
- `fbadlib-brief` di background menerima `temperature` opsional.
- Fix: progress analisa tidak lagi membuka ulang panel Top iklan yang sudah ditutup.
- Butuh Aktifkan AI + API Key. Paling akurat kalau Feedback Loop snapshot diimpor.
- Test: `test/e2e-pola-champion.js` (prompt memuat baseline + fakta, parser toleran
  code fence, clamp skor, vonis tak dikenal → UJI KECIL). Browser E2E: checkbox,
  hitungan tombol, alur sampai langkah DeepSeek (profil tes tanpa key → "AI belum aktif").
